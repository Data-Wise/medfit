## Assumptions

1. 0.15.0 is GitHub-only (CRAN deferred, #83), released from `dev` to `main` by the author's release process.
2. The plan lives under `planning/` (not `tasks/`), and the plan file owns task state.
3. Release is readiness-gated; earliest date 2026-12-24.
4. `fixed_x = TRUE` in 0.15.0 means the character-subset resolution of E-13, not a blanket flag.

## 1. Objective

Make the native SEM engine's defaults match lavaan's practice: `fixed_x = TRUE` and `meanstructure = TRUE`, announced
in 0.14.0 and flipped in 0.15.0, with evidence that structural results do not move and a documented account of what
does. Users: analysts calling `fit_sem()` / `fit_mediation(engine = "native")`, and dependents (probmed, RMediation,
medrobust, medsim, missingmed, mediationverse).

## 4. Project structure (touched areas)

`R/fit-sem.R` (formals, resolver), `R/native-defaults.R` (resolver, obsolete note), `tests/testthat/` (api-freeze,
the 21 rewritten tests, `helper-native-defaults.R`), `tests/sim/` (oracle script, gate pins), `NEWS.md`, `man/`,
`vignettes/articles/`, `planning/`.

## 5. Code style

Match the surrounding R: native pipe, `checkmate` at entry, snake_case, 120-column lines, US English. Plan-task code
goes test-first in a feature worktree.

## 6. Testing strategy

Per `CLAUDE.md`: independent oracle (lavaan with `fixed.x = TRUE`, `lm`), planted defect per requirement (e.g. a
resolver that overwrites an explicit `FALSE`), full suite on the final tree, and the dispatched gates on the OpenBLAS
runner. Frozen optimizer fixtures pinned at 1e-6.

**Risk tier.** The flip changes the parameter vector of every default fit: treated as high-risk. The PR body carries
the seven-item admission checklist (each ticked or `n/a: <reason>`); `R/fit-sem.R` is added to `tests/sim/risk-files.txt`
if not already there.

## 7. Boundaries

- **Always:** test-first; quote exact commands and counts; run gates on the runner; US English.
- **Ask first:** pushing, opening the PR, merging, tagging, any release step; changing the ADR decisions.
- **Never:** flip with a failing gate; write code on `dev`/`main`; add FIML or `missing =` to 0.15.0; commit `_agents_workspace/`.

## 8. Success criteria

All F-1 to F-13 met; both required gate shards green on the release PR; dependents evidence attached; NEWS states
what moves (logLik, npar, AIC/BIC, `coef()` names, retry seed) and what does not (structural estimates, SEs).

## 9. Documentation

NEWS behavior-change entry (a result changes, so minor bump with note, per the correctness-fix convention), the files
in F-11, and the 0.15.0 section of [BREAKING] #329 closed on release.

## 10. Out of scope

FIML and any `missing =` argument (0.16.0 candidate); removal of the options shim (0.16.0); CRAN submission (#83);
changing the AIC/BIC count to lavaan's.
