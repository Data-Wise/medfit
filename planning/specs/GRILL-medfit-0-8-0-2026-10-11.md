| G9 | Add `anova()` / a two-model LRT for nested `SEMFit`s to W4 (user request, 2026-10-11, after the RMediation handoff showed `mbco()` is a general two-model test and `mbco_sem()` is not). | **Added to W4** (user-directed). Design sketch, not yet reviewed: `anova(fit0, fit1)` returns diffLL `= n_obs * (f0 - f1)` (the same quantity `mbco_sem()` already computes per refit, `diff_ll = n_obs * (f - fit@f)`), df = difference in free-parameter counts, chi-square p-value, one row per model. Refuse: fits on different data or `n_obs`, a model pair that is not nested (df difference <= 0), `sampling_weights` fits (the weighted discrepancy is not a likelihood, as `mbco_sem()` already refuses), non-converged fits. Reason: a general LRT lets a later change cover bootstrap MBCO (parametric and semiparametric) on the `SEMFit` route without a new bespoke function. **Codex review 2026-10-11 (finding 1, accepted): boundary nulls.** `anova()` must detect a boundary null before computing a p-value: when a bound or inequality involving a tested parameter is active in either model (for example `a == 0` in the null against `a > 0` in the alternative), the statistic is a mixture of chi-squares, not chi-square(df). It must refuse ordinary chi-square inference for such cases (or warn exactly as `mbco_sem()` does today, `R/sem-mbco.R:140-165`), never return a silent p-value. A regression fixture keeps the existing `mbco_sem()` boundary warning and the G10 `(SEMFit, SEMFit)` route must show the same behavior. | G11 | Does a joint-significance / MBCO test for glm fits go into 0.8.0? | G13 | Validation of the minimum-of-k LRT for a product of k paths (k >= 3). | **A type I error simulation as a release gate** (recommended, accepted): serial three-path model; nulls with one, two and all three paths zero; several sample sizes; size at or below alpha plus Monte Carlo error; a power check; planted defect (refer the minimum to chi-square(2)) must fail. **Codex review 2026-10-11 (finding 2, accepted): that defect cannot fail the size check**, because chi-square(2) gives larger p-values, so the test is only more conservative and satisfies an upper bound on type I error. New script `tests/sim/sem-mbco-k-size.R`. If size exceeds alpha, k >= 3 support stays out of the release. The underlying claim (an intersection-union test) is the assistant's reasoning, unchecked until this gate runs. Rejected: citation only; k = 2 only. |
